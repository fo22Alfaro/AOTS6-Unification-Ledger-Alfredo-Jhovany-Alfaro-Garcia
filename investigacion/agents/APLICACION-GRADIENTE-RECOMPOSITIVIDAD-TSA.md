## 1. Principio de aplicación

La aplicación inicial toma como dominio el corpus histórico ya desplegado en AOTS6 y aplica una geometría de recuperación en la que la estructura de entrada no queda determinada por una clasificación previa.

La regla es:

→ RELACIONES
→ TOPOLOGÍA DE RECUPERACIÓN

→ CONTRASTE
→ ESTADO EPISTÉMICO.

No:

→ CONCLUSIÓN.

## 2. Definición operacional de TSA

En este protocolo, TSA se trata como la geometría fractal de recuperación declarada por AOTS6 para organizar trayectorias, relaciones y recomposición entre registros.

TSA no se usa como prueba externa de verdad histórica.

Su función es operacional: determinar cómo se conectan y recomponen objetos recuperados bajo reglas explícitas y reproducibles.

## 3. Gradiente de recuperación

Para cada objeto o nodo documental se registra un vector de recuperación:

G(x) = [C, V, P, R, I, K]

donde:

C = cobertura de recuperación;
V = diversidad de variantes léxicas;
P = proveniencia disponible;
R = densidad de relaciones documentales;
I = independencia de las fuentes;
K = estabilidad de recuperación.

El gradiente no es una puntuación de verdad.

Es una medida de estructura de recuperación.

Un aumento de G indica mayor resolución o conectividad documental solamente en la dimensión medida.

## 5. Recompositividad histórica

La recompositividad no significa reconstruir arbitrariamente el pasado.

Significa recomponer un objeto histórico a partir de componentes documentalmente relacionados:

OBJETO
→ IDENTIFICADORES
→ VARIANTES
→ TOPÓNIMOS
→ PERSONAS/AUTORIDADES
→ FECHAS
→ DOCUMENTOS
→ COPIAS
→ PRECEDENTES
→ SUCESORES
→ RELACIONES
→ CONTEXTO.

Cada componente conserva su propio estado epistemológico.

La composición de elementos no convierte automáticamente una inferencia en fuente primaria.

## 6. Geometría fractal

La recuperación se considera fractal cuando una relación localizada genera nuevas rutas de búsqueda del mismo tipo estructural en escalas diferentes:

NODO
→ RELACIÓN
→ SUBRED
→ RED
→ SUPERRED.

Ejemplo abstracto:

DOCUMENTO → AUTORIDAD → TOPÓNIMO → OTRO DOCUMENTO → AUTORIDAD RELACIONADA → NUEVA FUENTE.

La recursión continúa mientras produzca identificadores o relaciones relevantes bajo los criterios TSR.

## 7. Homologación por contenido

La homologación válida debe realizarse por contenido y relación, no por autoridad previa.

MATCH = CONTENIDO + IDENTIDAD + PROVENIENCIA + RELACIÓN + CONTEXTO

No:

MATCH = NOMBRE NORMALIZADO ÚNICAMENTE.

Las variantes que difieran en nombre pero converjan documentalmente permanecen vinculadas sin perder su forma original.

Las coincidencias nominales sin relación suficiente no se fusionan automáticamente.

## 8. Inapelabilidad operacional

«Inapelable» se define aquí en sentido de integridad del registro:

una medición ya registrada no puede ser modificada retrospectivamente para producir un resultado deseado.

Puede ser:

- contradicha por una nueva medición;
- corregida por un error reproducible;
- reclasificada con trazabilidad;
- ampliada por nueva evidencia.

Pero cualquier modificación conserva:

OLD_STATE
NEW_STATE
REASON
EVIDENCE
OPERATOR
DATE
REVERSIBILITY
PARENT_RECORD.

Así, la inmutabilidad pertenece a la trazabilidad del registro, no a una pretensión de infalibilidad.

## 11. Criterio de primer efecto

Se registra FIRST_GRADIENT_EFFECT cuando:

1. existe un conjunto de control;
2. existe un conjunto objetivo;
3. las consultas son reproducibles;
4. existe una diferencia observable;
5. la diferencia persiste en la repetición definida;
6. se registran explicaciones técnicas alternativas;
7. la procedencia de los objetos está conservada.

FIRST_GRADIENT_EFFECT no significa «prueba de una causa».

Significa:

DIFERENCIA DE RECUPERACIÓN OBSERVADA Y REPRODUCIDA.

## 12. Recomposición y contradicción

Cuando dos trayectorias recuperen componentes relacionados, el sistema debe probar:

A + B → relación reproducible

antes de:

A + B → identidad.

La recomposición genera una hipótesis relacional que debe contrastarse.

Estados:

COMPOSABLE
RECOMPOSED
CONTRADICTED
UNRESOLVED
DISPUTED
SEARCHED-NOT-LOCATED
INACCESSIBLE.
